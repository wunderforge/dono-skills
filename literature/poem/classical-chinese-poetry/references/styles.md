# 风格简档

Compose 时选用其一，或按用户指定折中。不要只堆诗人关键词。

## 盛唐明快型

- **语言**：自然流畅，少雕琢，避免生僻堆砌
- **句法**：节奏明快，允许较大空间跳跃
- **意象**：江河、山川、天地、舟行
- **修辞**：可适度夸张，避免连续典故
- **情绪**：外放、明朗、昂扬
- **避免**：晚唐式密集幽冷、宋词式细腻闺情

范诗：

```
朝辞白帝彩云间，千里江陵一日还。
两岸猿声啼不住，轻舟已过万重山。
——李白《早发白帝城》
```

## 中晚唐沉郁型

- **语言**：凝练精密，讲究炼字，用词沉稳
- **句法**：结构严整，对仗工巧
- **意象**：秋、江河、史事、人间忧患
- **修辞**：可用典故，以景写情
- **情绪**：深沉、忧思、厚重
- **避免**：轻佻词句、过度飘逸

范诗：

```
国破山河在，城春草木深。
感时花溅泪，恨别鸟惊心。
烽火连三月，家书抵万金。
白头搔更短，浑欲不胜簪。
——杜甫《春望》
```
