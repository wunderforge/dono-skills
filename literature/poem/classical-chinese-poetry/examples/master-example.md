# Master 模式示例

用户：写一首七言绝句，武汉东湖秋夜，怀念大学生活，不要太伤感。

## Interpret

- form: qijue
- theme: 毕业后轻微怀念
- scene: 东湖秋夜
- emotion: 淡淡怀念，非悲伤
- style: 盛唐明快型偏清淡
- mode: master
- 核心情感：毕业后淡淡怀念，不伤，湖上走一遭便释然

## Plan

- 统一场景：秋夜东湖岸边，可撑船
- 镜头：远景湖月 → 近景芦苇香 → 灯影勾旧岸 → 一篙过塘收住
- 转合落点：灯影把怀念收成「还像当年」；合句停在过塘，释然有余味，不直说大学、不说不必伤感

| 句 | 功能 | 意象 | 情绪 | 画面 |
|----|------|------|------|------|
| 1 | 起 | 东湖、秋夜、月 | 静 | 夜湖、月色生凉 ✅ |
| 2 | 承 | 风、蒹葭 | 清 | 风过芦苇，细香 ✅ |
| 3 | 转 | 灯影、旧岸 | 念，不伤 | 岸边灯影还像当年 ✅ |
| 4 | 合 | 一篙、烟水、横塘 | 释然 | 撑篙过塘 ✅ |

风险：月+湖是常见组合，避免再堆孤舟、岁月悠悠。

## 初稿

```
秋湖夜静月生凉，风过蒹葭作细香。
灯影还如旧时岸，一篙烟水向苍茫。
```

## Check（摘要）

- structure: pass（4×7）
- rhyme: pass（凉/香/茫 需以 validator 核韵部；若不同部则 fatal）
- meter: 选取得分最高的七绝格式；unclear 字交给句义判断
- 套话：无「岁月悠悠」

若 validator 报韵脚不同部，本轮只改韵脚，不改主题。

## Critique

- 转句「灯影还如旧时岸」把校园记忆收成岸影，未直说大学，可接受
- 「苍茫」略阔，与「不要太伤感」略冲，可炼

## Fix

「一篙烟水向苍茫」→「一篙烟水过横塘」（保持字数与已通过约束）

## Recheck

再跑 validator。通过则定稿。

## 定稿

```
秋湖夜静月生凉，风过蒹葭作细香。
灯影还如旧时岸，一篙烟水过横塘。
```

**【译文】**
秋夜的湖面静极了，月色里透出一点凉意。风从芦苇丛里过来，带着细细的香。岸边灯影还像当年那样，撑一支竹篙，烟水茫茫地经过横塘。

**【注释】**
- **蒹葭**：芦苇。
- **一篙**：一支撑船的竹篙。
- **横塘**：古地名，诗词中常借指湖岸、水乡渡口。

**【词句出处】**
- **蒹葭**：《诗经·秦风·蒹葭》「蒹葭苍苍，白露为霜」。
- **横塘**：贺铸《青玉案》「凌波不过横塘路」，以横塘写水边情思。
- **一篙烟水**：宋人写湖上常以篙、烟水入句，手法相类。
